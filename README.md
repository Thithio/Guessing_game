# Guessing_game

Jogo de adivinhação no terminal, feito no curso "Python: começando com a linguagem" da Alura (2023).

O computador sorteia um número de 1 a 100. Você escolhe a dificuldade (20, 10 ou 5 tentativas) e começa com 1.000 pontos. Cada chute errado tira a distância entre o chute e o número sorteado.

```bash
python3 Adivinhacao.py
```
